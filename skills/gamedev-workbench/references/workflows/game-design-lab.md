# 创意、机制与受众

输入：想表达的体验、团队能力、时间与资产预算、目标平台、个人偏好与已有约束。

1. 写下体验支柱和玩家在一分钟内反复做的动作。受众/类型暂以假设描述，列证据与反证。
2. 从动作、信息、资源、空间、风险、反馈、协作关系发散组合；给每个方向明确差异，而非只改题材。
3. 比较玩家价值、实现成本、内容消耗、学习负担与最危险假设；选低成本可玩的验证片段。
4. 用纸面或极简原型检验核心循环；记录玩家实际行为、困惑和决策，不让作者自评代替试玩。
5. 根据观察保留、调整或删除；把决定和重新考虑的触发条件写清。

交付：templates/concept.md、机制卡、原型与试玩问题。来源：K01、K02、K12、K13、K15、T10。销量、热门类型和受众规模需另外查证，标签不是收入预测。
