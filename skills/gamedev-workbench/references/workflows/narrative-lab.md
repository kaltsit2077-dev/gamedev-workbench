# 剧情与互动叙事

输入：玩家角色、人物欲望、冲突、可用场景与表现预算、玩家选择权限。

1. 写因果链和人物目标，把信息何时交给玩家与事件何时发生分开。
2. 标出选择、条件、状态变量、分支回收点和不可逆后果；区分叙事设定与游戏运行状态。
3. 为每段规定进入、跳过、重播、保存、恢复、取消和返回玩法的交接。
4. 先做可以独立试玩的对话原型。使用 ink/Twine/Yarn 前核验具体实现许可与引擎桥。
5. 用状态表走通所有可达分支、缺变量、重复进入和本地化长文本；安排真人阅读与选择观察。

交付：templates/narrative.md、分支/变量表、可试玩片段和演出契约。来源：K03、K04、K05。

验收：选择后果可理解，变量定义唯一，跳过不破坏游戏状态，回看与正式进度分离。
