# Shader 与效果

输入：体验目标、触发事件、时长/阶段、背景与镜头、平台、渲染管线、实例预算。

1. 拆成预兆、主体、余韵；分别说明形状、颜色、运动、材质、光和声音承担的信号。
2. 选择 Shader、粒子、动画、几何或后处理；先做一个可调参数的小样例。坐标空间、UV、线性/显示颜色、透明排序、深度和混合写入规格。
3. 实现事件接线与唯一控制者。测试重复触发、停止、暂停恢复、切场景、对象池复用和结束释放。
4. 在固定时间点捕获与动态播放中检查；覆盖亮暗背景、实际镜头与画质选项。headless 检查不能证明渲染正确。
5. 测多实例场景，区分 CPU、GPU、绘制、透明 overdraw 和粒子容量。先采样后调整一个变量并复测。

交付：可编辑源资源、触发契约、参数、动态预览、预算与验证记录；使用 templates/effect.md。来源：E03、E06、E07、E08、A04、A05。

验收：玩家能分辨重要信号，预警与真实判定一致，取消和退出不留效果，重复播放不累积节点。跨引擎共享意图与资源规格，不承诺同一份 shader 原码通用。


## 可执行时间序列

内置 `check-ui-effects --graphical` 可复现样例的重播、暂停、结束隐藏/空闲以及固定时刻 PNG。它提供一份可改为自有测试的流程，不判断任意 shader 的美术质量。对用户效果需显式绑定自身触发/推进/销毁入口，使用目标渲染器另测；不能把样例通过套用到真实效果。
