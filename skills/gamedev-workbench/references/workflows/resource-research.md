# 资源研究

输入：具体开发任务、引擎/版本、需要的操作、预算、在线与离线限制。

1. 先搜索本地目录，再查 find-skills、官方 MCP Registry、维护者仓库和官方文档。
2. 找到上游原始来源；聚合站只提供线索。规范化网址，辨别 fork、旧包名、弃用接口和商业升级版。
3. 分别登记能力声明、上游测试、本地复现、项目验证；保存精确版本/commit 与日期。
4. 对代码、文档、素材、服务条款分别核验。未知授权只保留链接，不复制再分发。
5. 用同一个小任务比较少量候选，给出采用理由、限制、安装计划与撤回方式；不按热度自动安装。

交付：templates/source.md，目录条目与试验记录。联网不可用时注明仅查询本地快照，不声称完成实时搜索。
