# 任务导航

先读取用户任务、现有项目约束与实际工具条件，再选择最少的相关工作流。

- 架构/依赖/状态所有权：architecture。
- 具体功能与接线：feature，按需加 ui 或 effects。
- 菜单/HUD/焦点/界面绘制：ui；不要默认交付网页。
- Shader/粒子/反馈/动效：effects。
- 报错/性能/试玩：validation。
- 类型/受众/创意/机制/关卡：design。
- 剧情/角色/选择/演出：narrative。
- 风格/建模/贴图/音频与资产：art。
- 工具/技能/资料选型：research。

CLI route 给出关键词建议，不会理解完整上下文；代理需要自行判断并解释选择。新功能可组合 design→architecture→feature→validation；不要无条件加载全部参考。

现有项目规则优先，外部模板不覆盖已有契约。先按任务打开对应引擎说明，工具缺少时明确缺口；不安装服务也能使用知识与方法。
