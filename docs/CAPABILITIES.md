# 当前能力与覆盖深度

覆盖方向较广，执行深度不均。这里用产物和证据区分“指导流程”和“运行工具”；它们都能使用，但不能相互代替。

| 工作内容 | 当前交付 | 执行深度 | 验证边界 |
|---|---|---|---|
| 项目规划与交接 | 沿用项目规则/决策/任务，按改动影响拆分可运行步骤；责任、依赖与恢复线索 | 技能方法与可选模板 | 长期真实多人使用与交接完整性评审 |
| Git 协作与集成 | 分支/工作树/未解决索引、大小写与元数据线索；语义合并、集成树回归方法 | 本地只读 review-git 与真实 Git 夹具；不联网不合并 | 不证明远端新鲜度或语义正确；二进制资源合并仍依赖编辑器 |
| 工程结构与代码架构 | 状态所有权、依赖/契约审查、迁移模板；Godot 入口/引用/命名继承/写入线索、阅读稿与前后对比 | Python 工具已测；静态分析不解析完整语义 | 源 UID、有限常量与简单命名继承有覆盖；运行时调用和状态所有权不是静态证明 |
| 已声明的模块依赖方向 | 显式模块/路径/allow 规则与 check-boundaries，保留违规边和未知项 | 五个有限工具回归，规则/输入边界和只读测试；当前消费 Godot 快照 | 不含运行时调用、信号/注入、状态单写者、入口/autoload 或当前树新鲜度 |
| 原生 UI / HUD / 菜单 | 布局、主题、状态绑定、焦点与返回工作流；原生控件助手 | 新原生菜单五视口、两字号、四十帧、一百二十一项检查，含嵌套焦点恢复 | 真实游戏菜单、文字扩展、物理键鼠/手柄、复杂栈恢复 |
| 功能与效果 | 接线、Shader/VFX 拆解、触发与清理、预算模板 | Shader 双环/闪光/火花共用时钟，重播/暂停/减弱运动/清理检查 | 复杂粒子/Shader、性能负载与实际游戏接入 |
| 回归与调试 | 独立 bugfix 流程：复现、假设、根因、失败回归、相关消费者与生命周期；可选修复记录 | 原生案例与冻结合并/故障任务验收器 | 更多未见故障、长期真实使用及真实计费记录 |
| 证据查看与分享 | 单文件离线 HTML，视口筛选、双帧对照、失败项和原报告下载；README 原图/派生 SVG | 本地浏览器实测，390px 单列；嵌入既有原始 PNG，不启动引擎 | 真实项目显式验证夹具接入；不把采样帧扩称为完整视频 |
| 创作工作区 | 体验到验收的需求关联/任务 DAG/可编辑草案；阶段/文件工作页与任务包导出 | 结构/有限模型检查、浏览器导出与 hash 实测；没有独立 AI 服务 | 连续真实制作、实时项目接入与可审查执行 |
| 项目测试与适配契约 | 明确配置、源快照、预览、显式执行和共同报告；Godot/Unity/Unreal/Web/Blender 入口 | Godot 副本与 Node 实跑；其他后端缺环境 blocked；Web 不含浏览器 | 真实项目回归、原生后端实跑、恢复与版本兼容 |
| 创意、机制、类型与受众 | 体验支柱、核心循环、成本/风险比较、原型与试玩问题 | 工作流、模板与资料入口 | 多轮可玩原型、真实玩家数据；不自动证明好玩 |
| 剧情与世界观 | 工作流、模板及布尔状态图检查 | 可执行条件/断链/软锁/无结局状态检查 | 整数条件、存档恢复和可试玩叙事案例 |

| 无障碍、本地化、输入 | UI/验证流程中的约束与验收点 | 样例仅覆盖注入动作与基础焦点 | 硬件/辅助技术/长文本与多语言实际验收 |
| 制作与发行 | 学习路径、范围控制、交付与发布材料 | 本工具本身具有测试/打包/公开发布流程 | 各商店和目标平台的实际产品案例 |

本项目不是自动建模器、自动绘画服务或统一编辑器控制平台。代理可按既有授权调用环境中的工具；技能目录中的链接不会自动安装或授予权限。
