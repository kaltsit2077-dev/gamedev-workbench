# 当前能力与覆盖深度

覆盖方向较广，执行深度不均。这里用产物和证据区分“指导流程”和“运行工具”；它们都能使用，但不能相互代替。

| 工作内容 | 当前交付 | 执行深度 | 下一处缺口 |
|---|---|---|---|
| 工程结构与代码架构 | 状态所有权、依赖/契约审查、迁移模板；Godot 入口/引用/写入线索、阅读稿与前后对比 | Python 工具已测；静态分析不解析完整语义 | 已补源 UID 与有限常量；仍需运行时动态引用、更多独立标注及真实重构核对 |
| 原生 UI / HUD / 菜单 | 布局、主题、状态绑定、焦点与返回工作流；原生控件助手 | 新原生菜单五视口、两字号、四十帧、一百二十一项检查，含嵌套焦点恢复 | 真实游戏菜单、文字扩展、物理键鼠/手柄、复杂栈恢复 |
| 功能与效果 | 接线、Shader/VFX 拆解、触发与清理、预算模板 | Shader 双环/闪光/火花共用时钟，重播/暂停/减弱运动/清理检查 | 复杂粒子/Shader、性能负载与实际游戏接入 |
| 回归与调试 | 复现/证据流程、引擎版本核验、隔离样例执行 | 可运行样例和配对任务验收器 | 项目自定义测试适配、更多固定任务及真实计费记录 |
| 证据查看与分享 | 单文件离线 HTML，视口筛选、双帧对照、失败项和原报告下载；README 原图/派生 SVG | 本地浏览器实测，390px 单列；嵌入既有原始 PNG，不启动引擎 | 真实项目显式验证夹具接入；不把采样帧扩称为完整视频 |
| 创意、机制、类型与受众 | 体验支柱、核心循环、成本/风险比较、原型与试玩问题 | 工作流、模板与资料入口 | 多轮可玩原型、真实玩家数据；不自动证明好玩 |
| 剧情与世界观 | 工作流、模板及布尔状态图检查 | 可执行条件/断链/软锁/无结局状态检查 | 整数条件、存档恢复和可试玩叙事案例 |
| 美术风格、建模与资产 | 风格规则、规格、导入、许可与致谢 | 工作流及只读资产清单/PNG头部/glTF依赖预检 | 实际导入、资产制作链与风格一致性评审 |
| 音频、数值、经济、关卡 | 学习导引和设计/资产工作流内的专项步骤 | 整数经济/收入敏感性已有执行器，其余为指导 | 混音事件、其他经济策略、灰盒与节奏工具 |
| 无障碍、本地化、输入 | UI/验证流程中的约束与验收点 | 样例仅覆盖注入动作与基础焦点 | 硬件/辅助技术/长文本与多语言实际验收 |
| 制作与发行 | 学习路径、范围控制、交付与发布材料 | 本工具本身具有测试/打包/公开发布流程 | 各商店和目标平台的实际产品案例 |
| 工具与知识发现 | 来源索引、许可/版本状态、离线 search/inspect 与任务 brief | 可执行离线工具；外部能力未复现 | 来源维护、过期检查、按真实缺口验证 MCP |
| Unity / Unreal / Web | 引擎指引；Unity/Unreal 新增原创独立案例与显式运行器 | 未装编辑器，未做本机引擎执行 | 对应环境实际运行与画面验收，不能借 Godot 结果背书 |

本项目不是自动建模器、自动绘画服务或统一编辑器控制平台。代理可按既有授权调用环境中的工具；技能目录中的链接不会自动安装或授予权限。
