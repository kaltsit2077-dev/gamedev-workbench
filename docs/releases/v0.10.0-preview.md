# GameDev Workbench 0.10.0-preview

可安装技能与离线工具，辅助 AI 处理项目架构、功能实现、Bug 修复、Git 协作和原生 UI/效果。

- Godot 分析补充简单命名继承，接入模块边界检查、阅读稿与快照对比。重复类名和遮蔽保留待核对；未索引基类、类型标注、任意调用和嵌套类型不作推断。
- 现有游戏同一 497 文件只读快照中，33 条事前核对的继承正例由旧版 0 条识别变为新版 33 条；游戏源码和索引不变。公开结果已脱敏，不代表全工程准确率。
- 新增原生架构修复案例：游戏状态误继承界面类，旧 0.9 漏检，新版指出依赖。修复前后均可编译、三个功能检查保持；同一契约验收从 3/4 变为 4/4。案例是原创预设缺陷，不是生产游戏故障或模型提效实验。
- 文档提供实操源码、命令和原始记录。原有菜单/效果、叙事、经济和资产工具继续可用。

本地 Windows / Python 3.14.3：99 项测试，95 通过、4 跳过（主机符号链接及 Windows 新行文件名限制）。原生案例实跑官方 Godot 4.7.2；证据保留环境诊断，未发现阻塞错误。跨平台状态以本提交 Actions 为准；CI 不安装引擎。技能格式、发行内容和解压验证分别检查。

下载包含独立技能 ZIP、完整项目 ZIP、既有可选离线 HTML 与 SHA256SUMS.txt。完整用法见 QUICKSTART，案例源码、命令和原始记录见 CASE-STUDIES。当前没有普遍提效、省钱、完整游戏质量、真人输入或性能的证明。
