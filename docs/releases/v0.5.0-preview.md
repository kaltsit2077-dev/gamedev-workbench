# GameDev Workbench v0.5.0-preview

继续完善面向个人与小团队的游戏开发技能、知识导引与离线工具。

- 原生长文本菜单：嵌套确认、焦点恢复、字号/减少运动设置；单时钟 Shader 双环、闪光与火花。Windows/Godot 官方版图形验证 121 项、40 帧，headless 81 项；另完成明确标为 OS automation 的窗口键鼠链路。
- 源 UID 头/旁车/import 索引、未知/冲突/备用路径线索、有限常量路径和局部遮蔽过滤。20 个手工标注回归从旧版 12/20 到 20/20，仅代表该集合，不是全工程准确率。
- 有限布尔叙事图的断链/软锁/无结局状态检查、确定性整数经济场景、清单式 PNG/glTF/GLB 资产依赖预检。
- Unity/Unreal 原创编辑器案例及显式临时副本运行器；本机未装编辑器，真实运行保持 blocked，没有安装 MCP 或激活许可。
- 派发前冻结完整验收的两轮设置事务配对：四组均 10/10，验收后返工均 0。有技能两轮耗时均更长，未证明提效。处理组使用 0.4，并未评估新 0.5 工具；实际 token/费用仍未知。新增汇总入口区分缺失、估算和带来源的实际记录。

实体键鼠完整步骤尚未形成通过记录，未连接实体手柄；合成事件与 OS 自动化都不替代实体设备验收。性能、玩家体验、第三方 MCP 与 Unity/Unreal 真实运行未获本轮证明。

完整项目 ZIP 包含案例、验收与证据；独立技能 ZIP 自包含工作流和工具。SHA256SUMS.txt 覆盖两个包。原创材料 Apache-2.0，外部来源保留各自权利。
