# GameDev Workbench 0.8.0-preview

本轮聚焦可安装技能如何实际辅助小型和中型游戏工程：架构、规划、完整实现、Bug 修复与多人 Git 集成。可视化是补充，创意、风格、原生 UI/效果等既有流程继续可用。

- 新增 planning、bugfix、collaboration 三个按需模式，项目规划/交接、复现与根因修复、多人 Git 分工与语义合并流程，以及可选修复/交接模板。
- 强化真实入口、状态所有者、失败/重入/清理路径、场景/资源接线和最终集成树回归；沿用项目自己的规则和记录，流程深度随影响调整。
- 新增本地只读 review-git：未解决索引、本地基准/上游分叉、变更、完整冲突标记及大小写/UID/.meta 线索。不 fetch 或改仓库，不保证远端新鲜度或语义正确；超限与未知明确降级。
- 原创 Godot 冻结合并/故障任务：独立两组均 13/13、共同验收后返工 0，阴性对照 4/13。处理组观察墙钟 336.6 秒，对照 298.1 秒；费用未知。没有证明新增技能提效或在中型团队长期有效，完整输入/处理快照/产物/限制随包提供。
- 对现有私有游戏仅进行 Git 只读检查，公开摘要不含项目标识、源码或私有报告。

本地 Windows / Python 3.14.3：84 项测试，80 通过、4 跳过（主机符号链接及 Windows 新行文件名限制）。新增原生验收使用 Godot 4.7.2 official；CI 不安装引擎，跨平台结果以本提交 Actions 为准。技能格式、可移植引用、发布内容检查和两份 ZIP 解压验证通过后发布预览。

下载包含独立技能 ZIP、完整项目 ZIP、已有画面与工作区的可选离线 HTML、SHA256SUMS.txt。HTML 沿用既有内容，不算新增运行证据。用法见 QUICKSTART；工程对照见 ENGINEERING-EVALUATION.md。本版没有安装第三方 MCP 或发布宿主专用插件。
