# GameDev Workbench 0.9.0-preview

新增模块依赖复查，以及规划、调试和生命周期检查方法。

- 新增 check-boundaries：按项目已声明的模块/路径/允许方向，复查已保存 Godot 分析快照中的显式资源引用；给出具体违规边，普通字符串、动态/未知 UID、失效/未覆盖路径保留 partial。它不读取当前源码或运行引擎，不证明全架构正确、状态单写者或源码新鲜度。
- 补独立可玩切片、正常路径差异取证、保存事实/派生缓存与恢复关联、离开状态后取消/拒收旧异步结果；遵循项目已有设计和规则。
- 五个有限工具回归：原案例符合，反向引用检出，动态/字符串/未知 UID 正确保留未知；例子属于随实现建立的回归，不是留出准确率或生产力研究。
