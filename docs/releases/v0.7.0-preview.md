# GameDev Workbench 0.7.0-preview

本轮将技能、知识与工具连接为本地优先的 AI 游戏开发工作台基础；它们仍可独立使用。

- 可编辑创作工作区：体验、机制、剧情、风格、UI、资产、实现交接、验收，带需求 ID、任务依赖、结构与有限模型检查。
- 离线任务页：切换阶段、查看草案文件/源 hash、下载当前任务包并交给宿主 AI；页面只读，不连接模型或自动执行引擎。
- 项目测试：显式选择源文件并冻结，默认预览 argv，--execute 才运行，原生版本/检查/退出码/源变化均验收；共同执行报告保留失败和未知。
- 五类后端入口：Godot、Unity、Unreal、Web、Blender。实际 Godot 项目 7 项/菜单 headless 81 项、Node 26.5.0 状态检查 2 项通过；其他编辑器未提供路径，blocked。Node 不代表浏览器界面通过。
- 外部官方源码评估：固定 8 文件、7 条边首轮全匹配，标签于首次运行前冻结；不是人类盲评或全工程准确率。源码保留 MIT 许可。
- 价值实验：三正常/三预设缺陷副本，专项工具补到了仅解析遗漏的三个问题。不是新增独立模型对照；实际费用、人类盲评和真实项目总收益仍待测。

下载：完整项目 ZIP、独立技能 ZIP、原始截图浏览器 HTML、创作工作区 HTML、SHA256SUMS.txt。两个 HTML 均可直接双击；创作工作区内容为可编辑源文件生成的只读草案快照。完整用法见 QUICKSTART 与工具配方。

本地 Python 3.14.3 共 74 项测试：71 通过、3 项因主机不能创建符号链接而跳过。工作页已在浏览器实测切换、文件预览、任务下载与 390px 布局。跨平台结果见本提交 Actions；CI 不运行原生引擎。首次受限进程/不可写目录失败被保留，只有在可运行进程与独立可写缓存取得的结果计作 Godot 通过。

长期方向与成熟门槛见 docs/PLATFORM.md；没有把当前离线工作页称为完整独立 AI 平台。
