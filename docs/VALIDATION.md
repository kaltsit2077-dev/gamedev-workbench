## 环境限制

本机部分临时目录允许 Python 写入，却不允许引擎写日志，已通过 --scratch 指向引擎可写缓存绕开；工具会把这类写入错误判失败。Windows 根证书存储读取报错属于单独保留的环境诊断，样例没有联网，也没有验证 TLS。verify-godot 仅将这条已知诊断与业务失败分开，其余 ERROR/SCRIPT ERROR、超时、非零退出码、缺 PASS 标记均不会计为通过。

CI 配置 Windows/Linux/macOS、Python 3.11/3.14，运行工具测试、目录和发布检查；只在 Linux 3.11 重跑完整打包。CI 不安装或启动引擎，不能扩张 Godot/其他引擎的支持声明。运行结果见 [Actions](https://github.com/kaltsit2077-dev/gamedev-workbench/actions)。发布检查是有限特征检测，不是任何私有内容都能自动识别的保证。

无匹配引擎时 blocked；headless 通过不能代替真实输入与画面。图形检查只是当前样例的确定性采样，不是任意用户工程验收或持续视频/性能测试。代码测试、案例存在、曾修好一个真实问题，都不能证明此技能比同模型无技能更快。本轮配对的处理组使用 0.2；0.3 工具没有接受生产力对照。
