# 长期路线与当前下一步

最终形态是本地优先的 AI 游戏开发平台，技能、知识与工具共享核心且可独用。[平台设计](PLATFORM.md)说明层次、完整制作旅程与能力门槛；本表按验证状态排序，不承诺日期。

| 阶段 | 当前落点 | 下一项必须拿到的证据 |
|---|---|---|
| 可靠分析 | 原有限回归 + 8 个外部作者文件的冻结评估；动态引用保留未知 | 新的未见项目、独立人类复核、实际建议前后价值 |
| 创作链 | 体验/机制/剧情/风格/UI/资产/实现/验收的可编辑草案、任务 DAG、离线工作页与任务导出 | 连续完成真实制作任务；风格参考、模型/声音/素材的真实产出与导入 |
| 项目执行 | 明确测试配置、源快照、计划预览、显式执行、失败/超时与共同报告 | 在真实游戏的授权场景接入原生 UI/VFX 检查，验证恢复与副作用 |
| 多后端 | Godot 实跑；JavaScript 状态案例实跑；Unity/Unreal/Blender 源码与入口 | 对应编辑器安装后实跑，Web 补真实浏览器行为/画面；每后端单独登记 |
| 实际收益 | 三类预设缺陷相对仅解析的检出试验；旧模型试验无提效结论 | 新版工具的独立同模型任务、人类盲评、全流程耗时与可追溯账单 |
| 项目工作台 | 离线只读快照，宿主 AI 继续执行 | 实时项目导航、可审查差异、任务取消/恢复与历史证据对应 |
| AI 与团队 | 开放任务/产物/报告契约 | 可替换执行者、预算用量、权限/兼容性，以及独立用户连续使用 |
| 扩展生态 | 来源与许可目录，按需方法与适配 | 源更新维护、真实编辑器缺口下的 MCP 同任务比较 |

实体输入、试玩和性能仍分别验证。未经真实环境执行的适配不得借其他引擎或单元测试通过背书；知识覆盖不等于自动制作能力。优先收集可复现问题和实际产物，不以集成数量作为成熟度。
