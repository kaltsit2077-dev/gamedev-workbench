# 后续完善路线

先把最常用任务做深，以真实请求与验收结果决定投入。这里是候选方向，不代表已实现或承诺日期。

| 顺序 | 具体工作 | 完成的判据 |
|---|---|---|
| 已推进，继续核验 | 原生嵌套菜单、分层效果与实际项目接入 | 原创可操作菜单和画面/OS自动交互已测；仍需完成实体键鼠/手柄、更多语言和真实项目集成 |
| 已推进，继续核验 | 源 UID 与有限常量路径 | 已有 UID 冲突/备用路径、遮蔽和标注回归；继续增加独立留出样本及运行时动态引用，保持只读与未知边界 |
| 已推进，继续核验 | 重复配对与真实费用 | 完整验收预先冻结的两轮新增对照已完成，未证明提效；继续独立盲评及新增工具处理组，实际费用待可追溯记录 |
| 近期 | 项目声明的测试入口与证据适配 | 可预览明确命令，超时/失败真实可见，用户场景副作用与隔离由配置说明 |
| 后续 | 一个编辑器 MCP 的实用对比 | 出现 CLI 无法解决的操作后，在同任务完成读/改/撤回/运行/停止与权限核对 |
| 环境待准备 | Unity、Unreal 的独立案例运行 | 原创源码与显式运行入口已提供；用户确认未安装，真实运行仍 blocked，后续需版本/产物/行为证据 |
| 已推进，继续扩展 | 叙事、经济、资产、音频与关卡 | 布尔叙事图、整数收支和资产依赖预检已交付；继续丰富条件/策略、真正导入、音频事件与灰盒关卡 |
| 持续 | 外部来源更新与社区反馈 | 新条目说明具体任务和来源，明确许可/依赖/费用，不因条目多就声称全面可用 |

更全面的地图已经存在；当前主要短板是代表性案例、跨引擎执行和独立用户验证。扩大功能应能解决具体制作问题。发布后通过仓库 Issues 收集复现与真实任务，优先处理可验证的阻碍。
