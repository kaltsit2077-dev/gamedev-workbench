# 预览版完善与发布评估

沿用已确认的 GameDev Workbench 设计；用户于 2026-11-11 要求进一步完善、使用说明与发布可行性评估。

本轮范围：修复英文子串错误路由；将任务导航完善为可执行任务资料包；把内置 Godot 样例纳入便携技能并提供隔离验证；补支持矩阵、评估方法和发布说明。不创建云平台，不连接第三方 MCP，不把当前私有游戏上传，不自动公开发布。

实施步骤：

1. 为 build/model、中文 UI、模块路由、项目路径缺失、错误引擎和隔离运行失败编写回归。
2. 将模式、关键字、工作流、模板、来源 ID 收到单一清单；brief 根据需求输出路径与项目约束指针。
3. 将样例移入技能 assets；verify-godot 先核验引擎，再在临时副本与隔离数据目录运行，不改用户工程。
4. 实测官方引擎；记录真实通过范围。测试和格式检查只能证明相应维度，不能证明模型提效。
5. 发布 0.2.0-preview 本地包，验证解压和安装；更新已安装的本项目技能前保留旧版并检查原文件未被用户改动。

验收：离线 CLI、来源引用、独立安装与解压验证；Godot 样例有实际结果；无引擎/错误版本不得报告成功。发布评估分别讨论技术可发布、使用价值与尚无证据的生产力收益。
