# 职责审计与最小修复

源锚点以文件与方法名定位，均指本隔离工程。

| 锚点 | 状态归属与具体问题 | 最小决定 |
|---|---|---|
| `state.gd` · `charge` / `trigger()` | 模型拥有电量；原来不断累加，超过上限。 | 在模型入口钳制到 5，保持原信号与接口。 |
| `state.gd` · `reset()` / `changed` | 模型归零后没有发通知，视图依赖下一帧刷新。 | 每次 reset 都发 `changed(0)`，包括已为 0 的情况。 |
| `ui.gd` · `_on_trigger()` | 视图直接修改模型字段，绕开模型行为与通知。 | 按钮继续接同一回调，改调 `model.trigger()`，然后重启反馈。 |
| `ui.gd` · `_ready()` / 原 `_process()` | 标签逐帧读取状态，按钮默认位置重叠。 | 订阅 `changed` 并立即同步初始值，移除轮询；仅分开标签和两个按钮的位置。 |
| `feedback.gd` · `trigger()` | 反馈拥有 `elapsed` / `active`；原来活动期间拒绝重触发。 | 每次触发清零时间并激活，不分配新节点。 |
| `feedback.gd` · `advance()` / `_process()` | 既有推进接口是唯一时钟路径，节点默认继承暂停行为。 | 保留该路径和默认 process mode，不引入 Timer、Tween 或暂停豁免。 |

所有既有字段、模型方法、信号及按钮回调保留。删除的是 UI 的逐帧内部回调，新增信号消费回调。没有改动真实游戏的正式文件、项目配置、依赖、真实存档或发布设置；运行环境按补充授权使用本组专用忽略缓存，见 `RESULT.md`。反馈原本只有逻辑状态，本次保留该范围，没有额外添加表现功能。
