# 小团队开发导引

按当前问题选择路径，不要求所有项目走完全部步骤。

| 阶段/任务 | 行动与产物 | 本地入口与来源 |
|---|---|---|
| 定位 | 体验支柱、平台、类型/受众假设和范围 | design；K01、K02、K12、K13 |
| 核心原型 | 动作/反馈/风险循环，验证最危险假设 | design→feature→validation |
| 工程底座 | 装配、状态、输入、存档和资源边界 | architecture；E01、K11 |
| 原生界面 | 状态、导航、主题、真实绑定 | ui；K06、K07 |
| 美术方向 | 风格规则与一个代表资产家族 | art；K08、K09、A09、A10 |
| 动画与效果 | 动作阶段、反馈层次、触发与预算 | effects；A04、E03、E06–E08 |
| 关卡 | 空间目标→灰盒→遭遇节奏→试玩 | design；K10、K15 |
| 叙事 | 选择、变量、表现成本与状态恢复 | narrative；K03–K05 |
| 数值/经济 | 资源来源、消耗、存量、参数敏感性 | design；T10（可选云工具） |
| 音频 | 事件表、优先级、循环、混音和致谢 | art；A11 |
| AI/寻路 | 状态机/行为树/效用选择，固定可观察行为与预算 | architecture→feature→validation；S03 |
| 联网 | 先决定是否必要；状态权威、同步、延迟与断线恢复 | architecture→feature→validation；S03 |
| 程序化内容 | 种子、约束、可解性、最坏输入与可复现 | design→feature→validation；S03 |
| 无障碍/本地化 | 重绑、字号、字幕、颜色冗余、长文本与阅读 | ui；K06 |
| 垂直切片 | 代表性的玩法、美术、UI、内容和发布路径 | guide；固定可玩的范围与删减依据 |
| 试玩 | 任务、观察、困惑、失败与复测 | validation；不自动认证好玩 |
| 发行 | 目标平台的构建/签名/商店/隐私与权限/依赖致谢 | K12、K13；发布前查对应平台最新官方要求 |

目录中的资料均按 ID 检索：`python scripts/workbench.py inspect K01`。商业书籍、免费网页与开放许可分开登记；默认不镜像正文、截图、音视频。进一步收录需先走 resource-research。
